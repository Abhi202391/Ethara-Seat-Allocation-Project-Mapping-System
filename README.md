# Ethara-Seat-Allocation-Project-Mapping-System
Full-stack seat allocation &amp; project mapping system for Ethara's 5,000+ employees. React + Tailwind frontend, FastAPI + SQLAlchemy + SQLite backend, with role-based auth (Manager/Employee), server-enforced allocation rules, and an AI assistant (OpenAI function-calling with a rule-based fallback) for natural-language seat/project queries.
